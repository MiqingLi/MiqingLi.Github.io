I have been fortunate to work with many talented researchers in other fields and develop evolutionary algorithms for practical optimisation problems. These applications include software testing, software configuration tuning, cloud workflow scheduling, automated product disassembly, emergency logistics, neural architecture design, and diverse play styles in reinforcement learning agents.
