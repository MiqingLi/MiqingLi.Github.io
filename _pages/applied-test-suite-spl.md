This work frames test-suite generation for software product lines as a multi-objective optimisation problem. The aim is to select a small, useful set of product configurations while covering important feature interactions and preserving diversity.

## Results Summary

- Multi-objective search can produce compact test suites that retain strong coverage.
- Quality-diversity methods offer a way to expose a broader range of useful test suites rather than a single narrowly optimised answer.
