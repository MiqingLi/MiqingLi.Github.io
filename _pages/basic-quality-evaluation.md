A key issue in multi-objective optimisation is how to evaluate and compare solution sets returned by different algorithms. This is not straightforward: the output is usually a set of mutually incomparable non-dominated solutions, and reducing the whole set to a scalar value requires careful indicator selection.

## Selected Work Themes
