A software product line is a family of software products derived from a shared set of features. A key challenge is how to sample, test, and optimise configurations when the full product space is extremely large.

## Topic Pages

- [Test-Suite Generation for SPL]({{ '/applied-research/software-product-line/test-suite-generation-for-spl/' | relative_url }})

## Selected Work Themes

- Selecting representative test suites that cover feature interactions while keeping test cost manageable.
- Using multi-objective search to balance coverage, cost, and diversity.
- Investigating how quality-diversity ideas can help generate useful SPL test suites.
