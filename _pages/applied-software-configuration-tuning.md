Modern software systems often expose many configuration options. Tuning these systems requires balancing objectives such as performance, latency, cost, resource use, and reliability, usually under expensive measurement budgets.

## Selected Work Themes

- Bi-objective modelling for software configuration tuning.
- Meta multi-objectivisation for configurable software systems.
- Lifelong and prior-knowledge-based adaptation when software environments change over time.
- Surrogate-assisted search for expensive configuration spaces.
