Add a new announcement by creating one Markdown file in this folder.

Recommended filename:

  YYYY-MM-DD-short-topic.md

The filename is only for humans. The site orders announcements by the `date`
field below, so you do not need to rename older files.

Template:

---
layout: post
date: YYYY-MM-DD 23:00:00+0000
inline: true
related_posts: false
---

Month YYYY - Announcement text goes here. Links can use Markdown syntax:
[link text](https://example.com).
